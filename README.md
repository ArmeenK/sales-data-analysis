# Sales Data Analysis

Analysis of a Superstore sales dataset (9,800 orders, 2015-2018) exploring revenue trends, category performance, and order processing times.

## What I did
- Cleaned missing values (Postal Code)
- Converted date columns and calculated order processing time
- Analyzed total and average sales by category
- Visualized sales trends over time and by category

## Key findings
- Technology generated the highest total sales ($830K), followed by Furniture ($720K) and Office Supplies ($700K)
- Sales showed a strong upward trend from 2015-2018, with recurring seasonal spikes (likely holiday season)

## Tools
Python, pandas, NumPy, Matplotlib
